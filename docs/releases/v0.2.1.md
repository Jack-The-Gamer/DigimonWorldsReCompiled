Digimon World, Digimon World 2 and Digimon World 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
Pick the zip for your system below, unzip it, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`).

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 0.2.0
- **Settings → BIOS** now holds everything about the BIOS: which BIOS each region starts with, the BIOS files you added (verified or not, with a warning if a file has gone missing, and **Remove**, which keeps the file), **Add BIOS…**, the choice between your BIOS and the built-in one, and fast boot. The bar under the game cards is gone. Dropping a BIOS dump on the window adds it.
- **Mod downloads fixed** where GitHub's download redirect failed with "chunk expected crlf" (seen through some proxies).
- The bundled Turbo Text and Play Time Tracker mods are gone; only the documented template ships with the program. **Turbo Text** is now in **Mods → Find mods**, published from the [mod index](https://github.com/Jack-The-Gamer/DigimonWorldsReCompiled-mod-index), which can now host mods itself as well as list mods kept in their authors' own repositories (see the [modding guide](https://github.com/Jack-The-Gamer/DigimonWorldsReCompiled/blob/master/docs/modding.md#publishing-a-mod)).

If you unzip 0.2.1 over 0.2.0, delete the old `mods/play-time` and `mods/turbo-text` folders next to the program, or simply unzip into a fresh folder: your saves, settings and installed mods live in your user data folder and are kept.
