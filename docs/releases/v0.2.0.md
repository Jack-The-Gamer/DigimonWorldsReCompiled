Digimon World, Digimon World 2 and Digimon World 2003 running natively on Windows, Linux and macOS — the games' own code recompiled to native code and run on a cycle-timed model of the PlayStation.

**You need:** your own disc image (`.bin`; a `.cue` is optional). A BIOS dump is optional: without one, the built-in open-source OpenBIOS starts the games. Nothing from the games or from Sony is included.

### Download
Pick the zip for your system below, unzip it, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`). On first launch, click **Scan a folder for discs…** and choose the folder with your `.bin` files.

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### In this release
- One launcher for all three games: hash-verified discs, memory cards compatible with other emulators, portable mode, keyboard and gamepad (R1 defaults to E).
- **Optional BIOS**: games start with the built-in OpenBIOS when you have not added a console BIOS; saves are byte-identical either way. Add your own BIOS for exact BIOS routines and fast boot.
- **Mods page**: install from `.zip` (button or drag and drop), switch mods on per game, load order, options, safe mode; **Find mods** browses mod indexes on GitHub (the [Re:Compiled index](https://github.com/Jack-The-Gamer/DigimonWorldsReCompiled-mod-index) is built in); mods that publish GitHub Releases get **Update** and **Versions** (roll back). Mod scripts run sandboxed.
- Developer tool `dwrc-cli`: inspect discs, run headless, disassemble, and `mod validate/pack/install` for mod authors.

See the [README](https://github.com/Jack-The-Gamer/DigimonWorldsReCompiled#readme), [modding guide](https://github.com/Jack-The-Gamer/DigimonWorldsReCompiled/blob/master/docs/modding.md) and [accuracy notes](https://github.com/Jack-The-Gamer/DigimonWorldsReCompiled/blob/master/docs/accuracy.md).
