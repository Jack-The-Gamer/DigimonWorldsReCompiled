Digimon World, Digimon World 2 and Digimon World 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
**Already on 0.2.2?** Click **Update to v0.2.3** at the bottom of the Games page. Otherwise pick the zip for your system below, unzip it, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`).

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 0.2.2
- **CRT filter** (Settings → Video → CRT): the picture drawn like a CRT television, with scanlines whose width follows brightness, a red/green/blue phosphor mask and a gently curved screen. Each effect has its own slider.
- **Games page** scales with the window: the three games are centred and grow to fill large screens (one column on narrow windows), with larger text and buttons to match.
- **Always dark.** With a light Windows or macOS theme the launcher drew dark text and light buttons on its dark background; it now keeps its own dark look whatever the system theme.
- The footer shows just the version number next to the Update button.
