Digimon World, Digimon World 2 and Digimon World 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
**On 0.2.2 or later?** Open **Settings → About** and click **Check now**, then **Update…** (versions before 0.2.5 may not notice a new release on their own for a few hours; see below). Otherwise pick the zip for your system below, unzip it, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`).

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 0.2.4
- **The update check now really runs at every start.** Earlier versions reused the answer from a check made in the last six hours, so a release that came out in between went unnoticed until that expired. The launcher now asks GitHub each time it starts, and every six hours while it stays open; the last answer is only used when GitHub can't be reached.
