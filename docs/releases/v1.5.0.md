Digimon World, Digimon World 2 and Digimon World 3 / 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
**Already playing?** The launcher offers this update when it starts: click **Update to v1.5.0** at the bottom left of the Games page (or open **Settings → About** and click **Check now**). It downloads the new version and replaces the program where it is; your games, saves, settings and mods are kept.

**New to Re:Compiled?** Pick the zip for your system below, unzip it anywhere, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`). Then click **Scan a folder for discs…** and choose the folder with your disc images.

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 1.4.0
- **Widescreen.** **Settings → Video → Widescreen** (16:9, 16:10 or 21:9) shows more of the picture at the sides, with nothing stretched: the parts of battles, fields and dungeons that a PlayStation cuts off at the edge of its 4:3 screen. Where a game drew nothing past the edge (menus, movies, the end of a map), the sides stay black. It is off by default.
- **Widescreen UI.** With it ticked, menus, panels and the HUD that sit against the left or right edge move out to the edges of the wider picture: in Digimon World 2003 the battle menu and the enemy's health go left, your partner's health and camera go right; in Digimon World 2 the party and enemy rows spread out; in Digimon World the clock, the field bars and the battle panels follow. Mod pictures near an edge move with them. Widescreen never changes how the games play: save states, memory cards and timing are the same with it on or off.
- **Fast-Forward keeps the music's pitch with other mods installed.** With Fast-Forward's "Normal pitch" setting, another mod that watches the game's code (DW3 Better DV EXP, Better Training, …) could make the music play higher while sped up. Fixed.
- **Mods that hook the same place in the game now all work.** Before, when two mods hooked the same game function, only the last one ran.
- **Find mods** cards no longer show thumbnails, and the launcher no longer downloads them.
- **For mod authors:** several `dwrc.on_exec` hooks on one address run in load order. `docs/dev-tools.md` has a new section, "Researching a game", on how the DW3 mods' game addresses were found.
