Digimon World, Digimon World 2 and Digimon World 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
Pick the zip for your system below, unzip it, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`).

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

**Coming from 0.2.1 or older:** unzip this release into a fresh folder (or over the old one). This is the last time: from 0.2.2 on, the program updates itself.

### Changes since 0.2.1
- **Updates from inside the program.** When a new version is released, an **Update** button appears at the bottom of the Games page. It shows the release notes, downloads the new version and replaces the program in place, keeping your games, saves, settings and mods; **Restart** finishes it. If anything goes wrong part-way, the old version is put back. **Settings → About** has the on/off switch and a **Check now** button.
- **Join the Discord** and **Support on Ko-fi** buttons at the bottom of the Games page.
