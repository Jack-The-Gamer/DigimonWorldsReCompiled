Digimon World, Digimon World 2 and Digimon World 3 / 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
**Already playing?** The launcher offers this update when it starts: click **Update to v1.1.0** at the bottom left of the Games page (or open **Settings → About** and click **Check now**). It downloads the new version and replaces the program where it is; your games, saves, settings and mods are kept.

**New to Re:Compiled?** Pick the zip for your system below, unzip it anywhere, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`). Then click **Scan a folder for discs…** and choose the folder with your disc images.

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 1.0.0
- **Several discs per game, and switching between them.** Re:Compiled now keeps every disc you import for a game, not just the last one: other regions, or other copies. On the Games page, click the release name under a game's title (for example *Digimon World (USA) · SLUS-01032 ⏷*). A list unrolls with each of your discs for that game: its release and serial, its file name, and whether it is a verified dump. Click one to play it from now on. The **✖** beside a disc takes it off the list; the file itself is not touched.
- **Japanese releases.** Digimon World (Japan, SLPS-01797) and Digimon World 3: Aratanaru Bouken no Tobira (Japan, SLPS-03446) are now recognised. Both boot and run on the built-in BIOS or on a Japanese console BIOS. The SCPH-5500 BIOS is now known, and a game uses the BIOS of its disc's region. They are marked as unverified dumps until they have been played through end to end.
- **Discs that were not recognised now are.** A `.cue` whose `.bin` was renamed now opens the `.bin` named like the `.cue` instead of failing. A second copy of a disc whose `.cue` points at the first copy is now added as its own disc, instead of being read through that `.cue`.
- **Faster folder scans.** Scanning a folder again no longer re-checks disc images that haven't changed since they were imported.
- **Better first choices.** When a scan finds several discs for a game that has none yet, a verified dump is picked first, then USA, Europe and Japan in that order.
- Documentation: Fast-Forward's L2 + R2 controls, the Japanese releases and serials (for mod authors), and Rust 1.85 as the minimum for building.
