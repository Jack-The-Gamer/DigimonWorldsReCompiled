Digimon World, Digimon World 2 and Digimon World 3 / 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
**Already playing?** The launcher offers this update when it starts: click **Update to v1.3.0** at the bottom left of the Games page (or open **Settings → About** and click **Check now**). It downloads the new version and replaces the program where it is; your games, saves, settings and mods are kept.

**New to Re:Compiled?** Pick the zip for your system below, unzip it anywhere, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`). Then click **Scan a folder for discs…** and choose the folder with your disc images.

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 1.2.0
- **Save states.** Re:Compiled can now save a game exactly where you are and bring it back, through the new **Save States** mod in **Mods → Find mods**: press **1** to **5** to save to five slots, and **Shift + 1** to **5** to load. A message over the picture says what happened. Each game release has its own slots, kept in your data folder, and loading a state never touches your memory cards, so your in-game saves stay as they are. A loaded state carries on exactly as the game did when it was saved, down to the music.
- **For mod authors:** mods can now react to keys on the keyboard (`dwrc.on_key`), save and load states (`dwrc.save_state`, `dwrc.load_state`) and show short messages on screen (`dwrc.notify`). See the modding guide.
