Digimon World, Digimon World 2 and Digimon World 3 / 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
**Already playing?** The launcher offers this update when it starts: click **Update to v1.4.0** at the bottom left of the Games page (or open **Settings → About** and click **Check now**). It downloads the new version and replaces the program where it is; your games, saves, settings and mods are kept.

**New to Re:Compiled?** Pick the zip for your system below, unzip it anywhere, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`). Then click **Scan a folder for discs…** and choose the folder with your disc images.

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 1.3.2
- **Mods can put pictures on screen.** A mod can now show a small image over the game, for example a sign while one of its switches is on. The first to use it is the new **DW3 Disable Random Encounters** mod in **Mods → Find mods**: press **R** to switch random battles off in Digimon World 3 / 2003, and **R** again to switch them back on. A red sign in the top right corner shows while they are off.
- **For mod authors:** `dwrc.show_image(name, file, opts)` shows a PNG from the mod's folder in a corner of the picture, and `dwrc.hide_image(name)` takes it away. Positions and sizes are on a 320×240 grid over the picture, so an image keeps its place in any window size and video mode. `dwrc-cli` screenshots include the images. See the modding guide.
