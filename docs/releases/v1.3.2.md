Digimon World, Digimon World 2 and Digimon World 3 / 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
**Already playing?** The launcher offers this update when it starts: click **Update to v1.3.2** at the bottom left of the Games page (or open **Settings → About** and click **Check now**). It downloads the new version and replaces the program where it is; your games, saves, settings and mods are kept.

**New to Re:Compiled?** Pick the zip for your system below, unzip it anywhere, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`). Then click **Scan a folder for discs…** and choose the folder with your disc images.

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 1.3.1
- **No more stutter when a battle starts or ends.** Digimon World 2003 used to freeze for a moment at transitions (up to a third of a second when a battle started, and longer right after loading a save state). The PlayStation itself never paused there: Re:Compiled was stopping the game while it converted newly loaded game code into code for your computer. That conversion now happens alongside the game, which keeps running at full speed in the meantime, and code the game loads again (the battle code, every battle) is reused instead of being converted again. The game plays exactly as before, down to its random numbers. Only the pauses are gone. All three games benefit.
- **Save states no longer restart Digimon World 2003.** With a console BIOS, the first state you loaded after starting the game could send it back to the language screen a little later, for example when you left Seiryu Tower or spoke to the Guardromon there. States now load correctly in a fresh session, including ones saved with earlier versions.
