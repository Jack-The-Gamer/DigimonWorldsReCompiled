Digimon World, Digimon World 2 and Digimon World 3 / 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
**Already playing?** The launcher offers this update when it starts: click **Update to v1.6.0** at the bottom left of the Games page (or open **Settings → About** and click **Check now**). It downloads the new version and replaces the program where it is; your games, saves, settings and mods are kept.

**New to Re:Compiled?** Pick the zip for your system below, unzip it anywhere, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`). Then click **Scan a folder for discs…** and choose the folder with your disc images.

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 1.5.1
Mods can now build content from the discs you own:
- **Mods can read and change the disc while a game loads.** A mod's script can read the game disc (with the changes of the mods loaded before it), replace sectors and add new data past the end of the disc. Digimon World 2 and 2003 keep their files without a real file system, so this is how a mod adds or enlarges their files. Your disc image itself is never changed.
- **Mods can read your other Digimon World discs.** A mod that names other games in its `mod.toml` (`uses_games = ["dw3"]`) can read the discs you play those games with, so it can build things from a game you own instead of shipping any of that game's data. The first mod to use it, **DW1 Expanded Roster**, brings Guilmon, Growlmon and WarGrowlmon from your Digimon World 2003 disc into Digimon World.

For mod authors: the new `dwrc.disc` and `dwrc.discs` functions are described in the modding guide (`docs/modding.md`), and `dwrc-cli run` takes another game's disc with `--other-disc`.
