Digimon World, Digimon World 2 and Digimon World 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
**On 0.2.5?** The launcher offers this update when it starts: click **Update** at the bottom left. **On 0.2.2 to 0.2.4?** Open **Settings → About**, click **Check now**, then **Update…**. Otherwise pick the zip for your system below, unzip it, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`).

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 0.2.5
- **Mods can run the game faster.** New in the mod API: `dwrc.set_speed(n)` runs the console up to four times faster, and the launcher keeps pace and still plays sound in real time. `dwrc.set_realtime_voices(mask)` keeps chosen sound chip voices at their normal pitch and tempo meanwhile, so a mod can leave the music alone while everything else speeds up. A **2x**/**3x** badge in the corner shows when a mod has sped the game up.
- **New mod: Fast-Forward** (in **Mods → Find mods**). Press **Select + Start** together for double speed, again for triple speed, and once more for normal speed. The music keeps its normal speed in all three games. Sound effects keep their normal pitch, or speed up with the game if you pick that in the mod's options.
- More for mod authors: `ctx:find(pattern)` searches memory for a byte pattern with wildcards, `dwrc.serial` gives the disc's serial, and `dwrc.on_exec` now works after the game has started too. See [docs/modding.md](https://github.com/Jack-The-Gamer/DigimonWorldsReCompiled/blob/HEAD/docs/modding.md).
- Fixed: a mod script that registered a callback or hook from inside its `on_frame` or `on_input` function froze the game.
