Digimon World, Digimon World 2 and Digimon World 3 / 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
**Already playing?** The launcher offers this update when it starts: click **Update to v1.2.0** at the bottom left of the Games page (or open **Settings → About** and click **Check now**). It downloads the new version and replaces the program where it is; your games, saves, settings and mods are kept.

**New to Re:Compiled?** Pick the zip for your system below, unzip it anywhere, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`). Then click **Scan a folder for discs…** and choose the folder with your disc images.

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 1.1.1
- **Digimon World 2003 at 60 Hz.** The European release has always played at 50 frames a second, about 17% slower than Digimon World 3 in the USA. Hidden inside it is a complete 60 Hz mode that the game never switches on. Re:Compiled now switches it on, so Digimon World 2003 plays at the speed of the USA release, with the music at the same tempo and the full picture on screen.
- It's on by default. To play at the original 50 Hz, untick **Settings → Video → Digimon World 2003 at 60 Hz**; the change applies the next time the game starts.
