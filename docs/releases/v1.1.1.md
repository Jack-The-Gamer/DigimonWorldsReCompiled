Digimon World, Digimon World 2 and Digimon World 3 / 2003 running natively on Windows, Linux and macOS. You need your own disc image (`.bin`; a `.cue` is optional); a BIOS dump is optional.

### Download
**On 0.2.5 or later?** The launcher offers this update when it starts: click **Update** at the bottom left. **On 0.2.2 to 0.2.4?** Open **Settings → About**, click **Check now**, then **Update…**. Otherwise pick the zip for your system below, unzip it, and run `DigimonWorldsReCompiled` (Windows: `DigimonWorldsReCompiled.exe`).

| | |
|---|---|
| Windows 10/11 (64-bit) | `DigimonWorldsReCompiled-windows-x64.zip` |
| macOS, Apple Silicon | `DigimonWorldsReCompiled-macos-arm64.zip` |
| macOS, Intel | `DigimonWorldsReCompiled-macos-x64.zip` |
| Linux (64-bit) | `DigimonWorldsReCompiled-linux-x64.zip` |

The builds are not code-signed yet: Windows SmartScreen may ask you to confirm ("More info → Run anyway"), and on macOS right-click the program and choose **Open** the first time.

### Changes since 1.1.0
- **Two more regions.** Digimon World (Europe, SLES-02914) and Digimon World 2 (Japan, SLPS-02844) now show up on the Games page alongside the USA, European and Japanese releases added in 1.1.0. Click the release name under a game's title to switch between the discs you have.
- Digimon World 3 (USA) has now been tested too. It and the newly recognised releases boot and run on the built-in BIOS or on their region's console BIOS. Like the Japanese releases, they are marked as unverified dumps until they have been played through end to end.
